Functions for calculating numerical values for Lagrange, Legendre, Hermite and Chebyshev orthogonal polynomials; alongside a benchmark for each class that plots the calculated values.

The functions pol[Name] take as input the number n of desired polynomials and the array x on which to calculate polynomials, and output values of all orthogonal polynomial from degree 0 to n-1 in class [Name]. On the i-th row of the output matrix are the values of the i-th polynomial.

The benchmark plot those values for each class.
